# Warframe Companion

A personal inventory and progression management application for Warframe players.

## About

Warframe Companion helps players organize their in-game collections, track inventory, and monitor their progression.

This is an independent companion application and is not affiliated with or endorsed by Digital Extremes.

## Planned Features

- Player Profile
- Currency Tracking
- Warframe Collection
- Relic Collection
- Mod Collection
- Weapon Collection
- Resource Tracking
- Foundry Crafting Tracker
